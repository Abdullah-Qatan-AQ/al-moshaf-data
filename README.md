# Al-Moshaf Data

مستودع عام لبيانات تطبيق **المصحف**، ويحتوي فقط على مصادر موثقة تسمح بإعادة التوزيع التجاري صراحةً.

> **تنبيه قانوني:** ملف `LICENSE` يغطي ملفات الفهرسة والبيانات الأصلية التي كتبها المشروع. البيانات الخارجية تحتفظ برخصها وإسنادها؛ راجع `DATA_LICENSES.md` قبل إعادة التوزيع.

## المحتوى

### القرآن العربي

- `quran/pages/ar/page-001.json` … `page-604.json`: النص العربي العثماني من Tanzil Project.
- `quran/uthmani-tanzil.txt`: النص العثماني الأصلي من Tanzil.
- الرخصة: CC BY 3.0 مع شروط Tanzil، وهي تسمح بالتوزيع التجاري الحرفي داخل التطبيقات مع الإسناد، ولا تفرض مراقبة التحديثات.

### التفسير

- `tafsir/en-mukhtasar.json`: التفسير الإنجليزي المختصر من Tafsir Center for Quranic Studies.
- الرخصة: CC BY 4.0، وتسمح بالاستخدام التجاري مع الإسناد ولا تفرض متابعة التحديثات.
- جرد وجود التفاسير المطلوبة موثق في [`tafsir/AVAILABILITY.md`](tafsir/AVAILABILITY.md).

### المحتوى الأصلي

- `devotional/adhkar.json`: أذكار وأدعية التطبيق.
- `devotional/names-of-allah.json`: أسماء الله ومعانيها.
- `devotional/ruqyah.json`: مواد الرقية الموجودة في التطبيق.

هذه الملفات موزعة ضمن نطاق MIT للمحتوى الذي أنشأه المشروع.

## ما لم يُضمّن

لم تُضمّن ترجمات أو تفاسير QuranEnc؛ شروطها المنشورة تشترط تحديث النسخة إلى أحدث إصدار ولا تنص صراحةً على الاستخدام التجاري. ولم تُضمّن ترجمات AlQuran.cloud لأن شروط الخدمة لا تمنح رخصة تجارية شاملة لكل ترجمة.

## الاستخدام داخل التطبيق

يستخدم التطبيق هذا المستودع مصدرًا أساسيًا للقرآن العربي والتفسير الإنجليزي والمحتوى الأصلي. إذا تعذر ملف القرآن العربي أو كان ناقصًا، يستخدم AlQuran.cloud للنص العربي فقط كـ API طوارئ؛ لا يستخدم التطبيق API للترجمات أو التفاسير.

## التحقق

```bash
sha256sum -c SHA256SUMS.txt
```

راجع [`DATA_LICENSES.md`](DATA_LICENSES.md) و[`manifest.json`](manifest.json) لمعرفة المصدر والرخصة والإسناد لكل ملف.

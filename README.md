# مستودع بيانات المصحف

مستودع بيانات موحد لتطبيق المصحف. يضم نص القرآن العربي من Tanzil، وتفسيري Tafsir Center العربي والإنجليزي، والمحتوى الأصلي للأذكار والأسماء والرقية.

## البنية

- `quran/pages/ar/`: صفحات النص العربي من Tanzil.
- `quran/uthmani-tanzil.txt`: بيانات البحث للنص العربي.
- `tafsir/ar-mukhtasar.json`: التفسير المختصر العربي، 6,236 آية، CC BY 4.0.
- `tafsir/en-mukhtasar.json`: التفسير المختصر الإنجليزي، 6,236 آية، CC BY 4.0.
- `devotional/`: محتوى أصلي مرخص MIT ضمن نطاقه.

لا توجد ترجمات خارجية مضمنة. جميع اللغات في التطبيق تعرض نص القرآن العربي نفسه؛ لا توجد اتصالات أي مصدر غير معتمد أو API للترجمة والتفسير.

## الإسناد والرخص

تفاصيل المصدر وشروط التوزيع التجاري في [`DATA_LICENSES.md`](DATA_LICENSES.md). بيانات Tafsir Center تسمح بالمشاركة والتعديل والاستخدام التجاري مع إسناد `Tafsir Center for Quranic Studies (https://tafsir.net)` ورابط [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) وبيان التغيير. لا تفرض الرخصة مراقبة التحديثات.

النص العربي من [Tanzil](https://tanzil.net) بترخيص CC BY 3.0 وشروط النسخ المطابق وعدم تغيير النص.

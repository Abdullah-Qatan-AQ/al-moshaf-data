# Tafsir availability

الملف المضمّن الوحيد هو `en-mukhtasar.json`، وهو التفسير الإنجليزي المختصر من Tafsir Center بترخيص CC BY 4.0 يسمح بالاستخدام التجاري مع الإسناد.

يستخدم التطبيق هذا الملف في واجهات العربية والإنجليزية والإندونيسية. لا توجد ملفات تفسير عربية أو إندونيسية منفصلة في مستودع البيانات.

استُبعدت مصادر QuranEnc لأن شروطها تشترط تحديث النسخة إلى أحدث إصدار ولا تنص صراحةً على الاستخدام التجاري. لا تُستخدم ترجمات أو تفاسير AlQuran.cloud كبديل؛ يقتصر API الطوارئ على النص العربي الذي تسمح شروطه بإعادة الإنتاج التجاري مع الإسناد.

راجع [`AVAILABILITY.md`](AVAILABILITY.md) لجرد الميسر والجلالين والبغوي والقرطبي وغيرهم.

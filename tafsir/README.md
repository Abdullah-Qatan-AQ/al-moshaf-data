# Tafsir availability

الملف المضمّن الوحيد هو `en-mukhtasar.json`، وهو التفسير الإنجليزي المختصر المرخّص CC BY 4.0. لا توجد ملفات تفسير عربية أو إندونيسية مضمنة في هذه النسخة.

السبب: لم يُتحقق من إذن موحّد وصريح لإعادة توزيع النصوص. توفر QUL وAlQuran.cloud الوصول أو التنزيل لا يعني تلقائيًا منح حق النسخ وإعادة النشر. شروط Tarteel العامة تحفظ حقوق Tarteel والمرخّصين له، وتمنع نسخ أو استخراج محتوى الخدمة ما لم يوجد إذن صريح.

يستخدم تطبيق Al-Moshaf التفسير الإنجليزي المضمّن كبديل في واجهة اللغة الإندونيسية. يستخدم التفسير العربي الميسر من QuranEnc عبر API وفق شروط المصدر، ولا ينبغي نسخ أي تفسير API إلى هذا المستودع قبل الحصول على إذن مكتوب أو رخصة واضحة من أصحاب الحقوق. راجع [`AVAILABILITY.md`](AVAILABILITY.md) لجرد الميسر والجلالين والبغوي والقرطبي وغيرهم.

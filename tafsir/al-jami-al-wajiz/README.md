- ملف البيانات يحتفظ بالنص العادي `tafsir_text` ونسخة HTML `tafsir_html` وبيانات السور `surahs`.
- جرى دمج ملفات المصدر في حاوية JSON واحدة دون تغيير قيم النصوص.
- يُرجى إبقاء ملف `LICENSE.txt` والإسناد عند أي توزيع.
